# May 11 : Completed Basic Prototype

Components i will be using 

- Nodemcu ESP8266
- mechanical switches 
- maybe a rotary encoder
- SPI oled display 1.3 inch
- Proboard
- and 3d printed case

The idea is to use Spotify API to control music playback of where my account is streaming, i will use nodemcu to connect to wifi and control it via the multiple input options i have given mostly i'm thinkking og having play/pause, next and previous options but thanks to the lib i found i can acstually do way more stuff like control volume so i'm also thinking of adding a volume knob now... 
It is a basic and easy project, which i'm working on as a stree reliever :) 


Wrote a basic code to check what stuff i can add and found a peak lib Spotify arduino which has many features and it will be very useful, Connected All the components on a breadboard to get a rough idea. Currently i have connected three microswitches but i ill use mechanical switches in the final project. I will start owrking on CAD of this as i won't be using a PCB for it rather a proto pcb is enough for this project.
